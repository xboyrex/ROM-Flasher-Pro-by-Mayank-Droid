# Support

When reporting an issue, include:
- Release version and exact downloaded asset name.
- Windows version and relevant driver/platform-tools versions.
- Device manufacturer/model/codename and mode (ADB/Fastboot), excluding IMEI or other personal identifiers.
- A concise description of expected versus actual behavior.
- Relevant console excerpt with account names/tokens/personal data removed.

Do not post passwords, access tokens, serial numbers, IMEI or private logs containing personal information.
