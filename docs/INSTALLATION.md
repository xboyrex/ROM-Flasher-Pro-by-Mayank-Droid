# Installation and first run

1. Open the [official Releases page](https://github.com/xboyrex/ROM-Flasher-Pro-by-Mayank-Droid/releases/latest) and confirm the intended version and asset name.
2. Download the executable from that release. This repository does not track the executable in its source tree.
3. Where a matching checksum is published, verify the SHA-256 against the same release asset.
4. Install the appropriate OEM USB driver and official ADB/Fastboot tools if the workflow requires them.
5. Enable Developer options / USB debugging only when required. Select the correct ADB or Fastboot mode.
6. Back up data and read all prompts before any flash, erase, wipe or bootloader operation.

Windows may show a warning for an unsigned or unfamiliar executable. Do not bypass security warnings unless the origin is independently trusted and the artifact has been verified.

## First-run checklist

- Confirm phone model, codename, region and slot state.
- Confirm firmware comes from a trusted source and matches the exact model.
- Use a reliable cable and direct USB port where possible.
- Stop if device status, partition names or package details conflict with trusted instructions.
- Verify the final device state independently after an operation.
