# Installation and first run

1. Download `ROM_Flasher_Pro_V6.exe` from the V6.0.0 release.
2. Verify its SHA-256 checksum against the release checksum manifest.
3. Install the appropriate USB drivers for your Android device if needed.
4. Enable Developer options and USB debugging only when required for the workflow.
5. Read all prompts before flashing or erasing partitions.
6. Back up data first. ADB/Fastboot operations can erase data or make a device unbootable when the wrong image or partition is selected.

Windows may display a security warning for unsigned or unfamiliar executables. Do not bypass warnings unless you independently trust the publisher and have verified the file.
