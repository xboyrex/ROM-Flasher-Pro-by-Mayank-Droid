# Security and safe-use policy

Do not submit passwords, access tokens, private keys, account recovery codes or personal data in issues.

Report suspected vulnerabilities through the repository's private security reporting feature if it is enabled. Otherwise, open a minimal public issue without sensitive exploit details and ask the maintainer for a private contact path.

Before running a Windows binary, verify its provenance and compare its checksum to the value for the exact release artifact. A checksum does not prove a program is safe. Android flashing/erase commands can cause permanent data loss or an unbootable device; use trusted instructions for the exact model.
