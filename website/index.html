05 / BEFORE YOU BEGIN

Make the safe path
the easy path.

A good interface still cannot protect a device from an incorrect firmware package. Verify the fundamentals before you start.

01

Verify the package

Check model/codename, region, package source, release notes and matching SHA-256 where available.

02

Confirm the device

Back up data, confirm ADB/Fastboot mode and install the correct OEM driver if needed.

03

Understand the action

Read the selected mode carefully. Wipes, partition erases and bootloader changes can be irreversible.

Flashing can erase data or make a phone unbootable.

Never select a ROM, partition or bootloader option by guesswork. Use trusted instructions for your exact device and stop when anything does not match.
