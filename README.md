## <img src="https://cdn.simpleicons.org/googlechrome/00E5FF" width="28" align="center" /> Overview

**ROM Flasher Pro** is a Windows-facing Android servicing toolkit that unifies **fastboot flashing**, **MiFlash/HyperOS workflows**, **kernel/recovery image selection**, **ADB/Fastboot diagnostics**, **WHQL driver installation** and **Windows memory optimization** into a single, safe, Bento-styled interface.

It is designed for Android modders, ROM testers and power users who need a repeatable, verifiable flashing pipeline — with explicit destructive-action guards, on-screen device identity checks and a clean read-only console.

> <img src="https://cdn.simpleicons.org/gitbook/F9AB00" width="16" /> **Note:** This repository contains documentation, screenshots, visual assets, the static website, release metadata, tests and publishing helpers. The original application source tree is not tracked here. Hotfix notes are consolidated from the supplied build log and are **not** a substitute for an independent source audit or device-specific validation.

## <img src="https://cdn.simpleicons.org/shieldsdotio/FF3B30" width="28" align="center" /> Safety & Scope

<img src="https://readme-typing-svg.demolab.com?font=Fira+Code&weight=600&size=16&duration=3000&pause=800&color=FF3B30&center=true&vCenter=true&width=700&height=40&lines=%E2%9A%A0%EF%B8%8F+Flashing+is+destructive.+Read+this+twice.+%E2%9A%A0%EF%B8%8F" alt="Safety Typing" />

</div>

Flashing, partition erasure, data formatting and bootloader changes **can cause irreversible data loss or leave a device unbootable**.

**Before you flash:**

- ✅ Back up all important data and confirm the exact device model/codename.
- ✅ Verify firmware provenance, package integrity and intended partition list.
- ✅ Treat `Format Data`, `Erase Userdata`, `Clean All` and **bootloader relocking** as potentially destructive.
- ✅ Stop immediately if device detection, selected workflow or on-screen status conflicts with trusted device-specific instructions.

**Do not:**

- ❌ Select **Clean All & Lock** unless trusted, device-specific release instructions explicitly permit relocking with that exact firmware.
- ❌ Use EDL/9008 flows outside an authorized and device-appropriate process.
- ❌ Interrupt a flash or EDL session — it can permanently brick the device.
- ❌ Run other ADB/Fastboot tools simultaneously with this toolkit.

> ⚠️ The repository's screenshots show the user interface, not the application's source code or an assurance that each operation is safe on every model. Use device-specific maintainer instructions and independently verify the resulting device state.
