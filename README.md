## Overview

ROM Flasher Pro by **Mayank Droid** is a Windows desktop project for Android flashing workflows. This repository contains the application, supporting scripts, documentation, release information and screenshots.

> **Safety first:** flashing the wrong image or using the wrong procedure can erase data or leave a device unbootable. Confirm the exact device model, package and instructions before proceeding.

- **Focused workflow** — access the project's flashing utilities through its desktop interface.
- **Repository transparency** — review source files, documentation, changes and reported issues.

- **Setup documentation** — review the project docs before connecting or modifying a device.

Download from the official GitHub Releases page:

**[Open latest release](https://github.com/xboyrex/ROM-Flasher-Pro-by-Mayank-Droid/releases/latest)**

Direct asset link, when available:

[ROM_Flasher_Pro_V6.exe](https://github.com/xboyrex/ROM-Flasher-Pro-by-Mayank-Droid/releases/latest/download/ROM_Flasher_Pro_V6.exe)

Always read the release notes and verify the checksum for the exact version downloaded. Do not rely on a checksum copied from an older release.

### Verify SHA-256 on Windows

Open PowerShell in the folder containing the downloaded file:

```powershell
Get-FileHash .\ROM_Flasher_Pro_V6.exe -Algorithm SHA256
```

Compare the output with the SHA-256 value listed for that same asset in the official release.

## Before you start

1. Back up important data.
2. Confirm the exact device model and supported flashing method.
3. Install appropriate OEM USB drivers if required.
4. Use a reliable cable and keep the device sufficiently charged.
5. Follow the release documentation and on-screen prompts.
6. Stop if the detected device, image or partition does not match your instructions.
