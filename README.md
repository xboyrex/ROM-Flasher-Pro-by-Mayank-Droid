## <img src="assets/icons/terminal.svg" width="22" height="22" align="center" alt=""> Overview

ROM Flasher Pro by **Mayank Droid** is a Windows desktop project for Android flashing workflows. This repository brings together the application, release downloads, documentation and project updates.

> [!CAUTION]
> Flashing the wrong image or using an unsupported procedure can erase data or leave a device unbootable. Confirm the exact device model, package and instructions before proceeding.

### Verify SHA-256 on Windows

Open PowerShell in the folder containing the downloaded file:

```powershell
Get-FileHash .\ROM_Flasher_Pro_V6.exe -Algorithm SHA256
```

Compare the result with the SHA-256 value published for that exact asset in the official release.

## Before you flash

- [ ] Back up important data.
- [ ] Confirm the exact device model and supported flashing method.
- [ ] Install appropriate OEM USB drivers if required.
- [ ] Use a reliable cable and keep the device sufficiently charged.
- [ ] Read the release notes and device-specific instructions.
- [ ] Stop if the detected device, image or partition does not match your instructions.
